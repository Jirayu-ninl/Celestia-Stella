### Project Celestia

My personal ecosystem <br>
Consists of

- **Celestia: Cosmos** → Central Hub – The main webApp of the Celestia ecosystem, portal for users, and businesses to interact with services, access data, and manage their workflows.
- **Celestia: Nexus** → Web3 & Financial Services Gateway – Handles blockchain integration, decentralized identity, trading, and payment processing across the ecosystem.
- **Celestia: Nebula** → Monitoring & Control Layer – Manages system health, service orchestration, and operational oversight with real-time dashboards and alerting.
- **Celestia: Astra** → Analytics & Background Processing – Processes data asynchronously for analytics, recommendations, and complex computations.
- **Celestia: Interlink** → Event Routing & Queuing Server – Manages high-speed communication between services via pub/sub, streaming, and job queues.
- **Celestia: Stella** → Data & API Gateway – Acts as the entry point for external integrations and internal data access, routing requests securely and efficiently.
- **Celestia: Stargate** → Authentication & Identity Management – Provides secure login, authorization, role management, and account federation.
- **Celestia: Orion** → Asset Storage & Data Center – Handles asset management, file storage, CDN distribution, and structured/unstructured data hosting.
- **Celestia: Chronicle** → Event Logging & Historical Data Service – Captures, validates, and stores events and activities for auditing, analytics, and replay.
- **Celestia: Station** → Shop & Marketplace – Offers an integrated marketplace for applications, plugins, and digital goods.
- **Celestia: Outpost** → Demo & Experimentation Hub – Showcases interactive demos, prototypes, and proof-of-concept projects.
- **Celestia: Constella** → Documentation & Knowledge Base – Hosts technical docs, changelogs, and API references for developers.
- **Celestia: Singularity** → AI Core Engine – Provides reasoning, retrieval-augmented generation (RAG), memory management, and automation logic.
- **Celestia: Horizon** → AI Platform & Workflow Layer – Enables AI-driven workflows, knowledge networks, and integration with business processes.

see at: [**TheIceJi**](https://theiceji.com)

#### Build project

**Install**
```
bun install
bun run db
```

**Dev**
```
bun run dev
```

**Build**
```
bun run build
```

**Start**
```
bun run start
```
